Create blank project

    Submit Create Project Form

Create template project
    Navigate To Project Page  TemplateProjectUrl
    Select Project Template  Ruby on Rails
    Input Project Name  ProjectName
    Select Visibility Level  Private
    Submit Create Project Form
    Verify Page Should Contain Project 'First project' was successfully created.

Update name of template project
    Navigate To Project Settings  ProjectName
    Clear Project Name Field
    Input Project Name  UpdatedProjectName
    Submit Save Changes Form
    Verify Page Should Contain Project was successfully updated.

Delete template project
    Navigate To Project Settings  UpdatedProjectName
    Click Delete Project Button
    Input Project Name Confirmation  UpdatedProjectName
    Confirm Delete Project
    Verify Page Should Contain Project 'Updated project' is in the process of being deleted.
